# TIKI Store — Roblox Recovery

Versi UI baru untuk website TIKI Store.

## Perubahan utama
- Banner utama diganti memakai banner TIKI Store yang diberikan.
- Popup promosi lama dihapus agar halaman langsung masuk ke website.
- Tampilan di-upgrade menjadi layout modern dark-green dengan animasi ringan dan responsif.
- Ditambahkan kartu layanan, status **STORE ONLINE / LAYANAN 24H**, dan alur cara order.
- Lookup username Roblox tetap menggunakan endpoint `/api/roblox`.
- Form recovery dilengkapi pilihan masalah, durasi, kronologi, lalu diteruskan ke WhatsApp.
- Semua tombol WhatsApp mengarah ke `https://wa.me/6283852538743`.
- Website tidak meminta password Roblox.

## Deploy Vercel
Upload isi folder ini ke root repository lalu deploy ke Vercel. Tidak diperlukan `vercel.json`.
